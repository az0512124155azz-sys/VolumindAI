# Volumind AI — התקנה מהירה

Volumind AI מחבר את Ollama לזרימת עבודה בטוחה ב־Fusion 360: תיאור → קוד לבדיקה → אישור → בנייה.

## הכנה למחשב עם 16GB RAM

```powershell
ollama pull qwen2.5-coder:3b
ollama pull qwen2.5vl:3b
ollama serve
```

אין צורך למחוק את מודל 32B, אך לא מומלץ להפעיל אותו במקביל ל־Fusion 360.

## התקנה

1. חלץ את תיקיית `VolumindAI` מתוך ה־ZIP.
2. העתק אותה אל `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns`.
3. ב־Fusion פתח `UTILITIES` → `Scripts and Add-Ins` → `Add-Ins`.
4. בחר `VolumindAI`, לחץ `Run`, ואפשר `Run on Startup` אם תרצה.
5. פתח מסמך Design ולחץ על Volumind AI בסרגל.

## פתיחה מהירה עם Shift+Q

Fusion אינו מאפשר לתוסף לשייך קיצור מקלדת גלובלי בעצמו, ולכן נדרשת הגדרה חד־פעמית:

1. אתר את Volumind AI בסרגל הכלים של Fusion.
2. לחץ על תפריט שלוש הנקודות שליד הפקודה ובחר `Change Keyboard Shortcut`.
3. הקש `Shift+Q` ואשר.

מעכשיו `Shift+Q` יפתח את הצ׳אט וימקד מיד את שורת ההודעה. `Q` לבדו ימשיך להפעיל Press Pull.

אם הקיצור אינו מגיב, ודא שהתוסף מסומן `Run on Startup`, פתח סביבת `Design`, והפעל פעם אחת את Volumind מהסרגל לפני בדיקת הקיצור. לאחר התקנה מחדש ייתכן שצריך לשייך את הקיצור שוב.

## חיבור ל־Volumind Remote באנדרואיד

גרסה 3.2 מפעילה API מקומי ב־`127.0.0.1:8765` עבור מחבר Windows. ה־API מקבל פקודות, קבצים, תשובות לשאלון ועצירה, ומשדר בחזרה תוכנית בנייה, התקדמות וצילומי viewport. קוד הצימוד נשמר בין הפעלות, ובהגדרות מופיעה נורה ירוקה כאשר הטלפון מחובר בפועל. ה־API מאזין רק למחשב המקומי ואינו חושף את Fusion או Ollama לאינטרנט.

## מה השתנה

- קריאת Ollama מתבצעת ברקע ואינה חוסמת את ממשק Fusion.
- ברירת המחדל המהירה היא `qwen2.5-coder:3b` וחלון הקשר 2048.
- צילום viewport עדיין נשמר אחרי כל שלב; בדיקת Vision נוספת ניתנת להפעלה בהגדרות.
- `qwen2.5vl:3b` בודק צילום viewport אמיתי אחרי כל שלב; ללא צילום ובדיקה מוצלחים הבנייה נעצרת.
- בקשה עמומה מפעילה שאלון קצר שנעלם מיד לאחר השליחה.
- המודל נבנה שלב אחר שלב וה־Timeline מתמלא בהדרגה.
- הקוד הוא מנגנון פנימי ומוסתר בפרטים הטכניים.
- סריקה חוסמת imports, קבצים, רשת, `eval`/`exec`, לולאות `while` וגישה פנימית.
- סטודיו לפרומפט הופך רעיון קצר למפרט הנדסי לפני יצירת הקוד.

מומלץ לשמור גרסה של המסמך לפני כל הרצה. קוד CAD שנוצר ב־AI עדיין עשוי להיכשל בגלל מגבלות Fusion API.
