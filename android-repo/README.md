# Volumind Remote

אפליקציית Android לשליטה מאובטחת ב־Volumind AI מכל מקום ולצפייה בהתקדמות המודל ב־Fusion 360.

הלוגו המקורי של Volumind כלול גם כאייקון האפליקציה וגם בכותרת הצ׳אט.

## מה כבר קיים

- צימוד למחשב באמצעות קוד קבוע בן 6 ספרות שנשמר מקומית.
- צ׳אט חי ושליחת פקודות ל־Fusion.
- העלאת תמונות וקובצי טקסט/קוד מהטלפון, או הדבקת קוד מתוך כפתור הפלוס.
- תוכנית בנייה והתקדמות שלב־אחר־שלב.
- מסך **מודל חי** שמתעדכן בצילום חדש אחרי כל שלב.
- שירות רקע שממשיך לקבל את תהליך הבנייה גם כשהאפליקציה אינה פתוחה.
- התראות כשהבנייה מתחילה, כשנדרשת תשובה, כשהיא נכשלת וכשהמודל מוכן — גם אם הבנייה התחילה מתוך Fusion.
- כפתור עצירת חירום.
- Relay עם חיבורים יוצאים בלבד; אין חשיפה ישירה של Ollama או Fusion.
- חסימת HTTP לא מוצפן באפליקציית Android.

## מבנה

- `app/` — אפליקציית Android ב־Kotlin ו־Jetpack Compose.
- `relay/` — שרת WebSocket קטן לפריסה מאחורי HTTPS/WSS.
- `bridge/` — מחבר Windows שיוצר חיבור יוצא ומעביר פקודות לתוסף Fusion דרך localhost.
- `fusion-addin/VolumindAI/` — תוסף Fusion 360 גרסה 3.3.0 עם API מקומי וחיבור מלא לטלפון.

## הפעלה לפיתוח

1. פרוס את `relay/` בשירות שתומך ב־Node ו־WebSocket והפעל TLS.
2. כתובת Render הנוכחית כבר מוגדרת באפליקציה: `wss://volumindai.onrender.com/ws`.
3. פתח את תיקיית המאגר ב־Android Studio ובנה את האפליקציה, או הרץ `gradlew.bat assembleDebug`.
4. העתק את `fusion-addin/VolumindAI` אל `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns` והפעל אותו מתוך Fusion.
5. מתוך תיקיית `bridge` הרץ `Set-ExecutionPolicy -Scope Process Bypass`, ואז `./run_bridge.ps1`. אפשר גם להריץ את הסקריפט בנתיב מלא מכל תיקייה.
6. הזן באפליקציה את קוד הצימוד בן שש הספרות שמופיע בחלון PowerShell.

קוד הצימוד מוצג בתוך `הגדרות` בתוסף Fusion רק אחרי שה־Relay אישר שהוא פעיל, ומחבר Windows קורא אותו אוטומטית. הקוד נשמר במחשב ואינו משתנה בכל פתיחה של Fusion. בהגדרות מופיעות נורות נפרדות למחבר Windows ולטלפון.

## החיבור לתוסף Fusion

תוסף Fusion המצורף מפעיל API מקומי ב־`127.0.0.1:8765`. הוא מקבל פקודות, תשובות לשאלון ועצירה, ומחזיר תשובות צ׳אט, תוכנית בנייה, סטטוס שלבים וצילום viewport אמיתי אחרי כל שלב.

## מה עדיין דורש הגדרה לפני שימוש מכל מקום

- כתובת שרת ציבורית עם HTTPS/WSS עבור `relay/`.
- הגדרת `VOLUMIND_RELAY_URL=wss://.../ws` במחשב שמריץ את Fusion.

## אבטחה

אין לפרוס את ה־relay ללא TLS. אין לחשוף את Ollama (`11434`) או את API ה־Fusion המקומי לאינטרנט. ה־Relay שומר רישום קוד רק בזמן שהמחבר פעיל ועד 24 שעות לאחר שהתנתק; הסוד הקבוע של המחשב מונע השתלטות על אותו קוד ב־Relay.
